🎬 Netflix Data Analysis

A comprehensive end-to-end data analysis of Netflix's content library using Python, SQL, Excel, and Power BI — uncovering trends in content distribution, genre patterns, country-wise production, and temporal growth.


📌 Project Overview
This project performs an in-depth exploratory data analysis (EDA) on Netflix's movies and TV shows dataset. The goal is to extract meaningful insights about Netflix's content strategy, production trends, and catalogue composition through data cleaning, SQL querying, statistical analysis, and interactive dashboards.

🎯 Objectives

Analyze the distribution of content types (Movies vs. TV Shows)
Identify top genres and their evolution over time
Explore country-wise content production and contribution
Study temporal patterns in content addition and release
Uncover rating distributions across different content categories


🛠️ Tools & Technologies
ToolPurposePython (Pandas, NumPy, Matplotlib, Seaborn)Data cleaning, EDA, visualizationSQL (MySQL)Data querying and business questionsMicrosoft ExcelPreliminary analysis and formattingPower BIInteractive dashboards and reporting

📂 Dataset

Source: Kaggle — Netflix Movies and TV Shows
Size: ~8,800 records
Key Columns: show_id, type, title, director, cast, country, date_added, release_year, rating, duration, listed_in, description


🔍 Key Findings

Netflix's catalogue consists of significantly more Movies than TV Shows
Content additions peaked around 2018–2019, with a gradual decline post-pandemic
The USA leads in content production, followed by India and the UK
Drama and International content dominate the genre landscape
TV-MA and TV-14 are the most common content ratings


📊 Deliverables

Cleaned and analysis-ready dataset
SQL scripts for business questions
Python notebooks for EDA and visualizations
